# OpenLab Legacy Record

**Status:** Historical archive / superseded architecture  
**Archive date:** September 2026  
**Current development:** https://github.com/porroto/Agentic-Education

## Purpose

This repository is intentionally preserved as evidence of OpenLab's early design history.

The original OpenLab work explored blockchain, Web3, IPFS, smart contracts, digital wallets, and a **Smart Academic Token (S.A.T.)** model for representing learning achievements and validation.

These artifacts document genuine exploratory work, but they no longer represent the project's current architecture.

## Transition

The project evolved away from treating a token or blockchain ledger as the center of the learning system.

Current work emphasizes:

- learner agency and ownership;
- meaningful learning opportunities;
- evidence and reflection;
- authorized validation;
- non-financial trust and recognition;
- responsible AI with explicit governance boundaries;
- proof-of-learning;
- embodied and field-learning prototypes.

The current repository is **Agentic-Education**:

https://github.com/porroto/Agentic-Education

## Terminology note

References in this archive to **Smart Academic Token**, token minting, blockchain credentials, smart contracts, wallets, or decentralized learning rewards are **historical terminology and implementation experiments**.

They should not be assumed to describe current S.A.T. terminology, governance, validation, or architecture.

## Preservation policy

The historical source files are intentionally retained. The purpose of this archive is provenance, not continued development.

New canonical specifications, prototypes, missions, governance documents, and engineering milestones should be developed in Agentic-Education rather than here.
